# Platform icon extension

Extension of the existing cream editorial list: keep typography, spacing rhythm, link behavior and statistics. Replace 6px brand dots and letter badges with 20px real favicons, with 8px title spacing and 28px text indentation. No added motion. Design dials: variance 2, motion 1, density 5, asset dependence 8, fidelity 10. Mobile recognition is the purpose of this bounded change.

Assets are stored in `public/platform-icons/` and served with the app:

| Platform | Asset | Source |
| --- | --- | --- |
| Dribbble | dribbble.png | https://dribbble.com/images/favicon-64x64.png |
| GitHub | github.svg | https://github.githubassets.com/favicons/favicon.svg |
| 花瓣 | huaban.ico | https://st0.dancf.com/static/02/202307111127-39d3.ico |
| 掘金 | juejin.png | https://lf-web-assets.juejin.cn/obj/juejin-web/xitu_juejin_web/static/favicons/favicon-32x32.png |
| Stack Overflow | stackoverflow.ico | https://cdn.sstatic.net/Sites/stackoverflow/Img/favicon.ico |
| Behance | behance.svg | https://cdn.jsdelivr.net/npm/simple-icons@15/icons/behance.svg |
| 站酷 | zcool.svg | https://cdn.jsdelivr.net/npm/simple-icons@15/icons/zcool.svg |

Behance and Zcool use the Simple Icons distribution (CC0); brand trademarks remain their owners' property. The other assets are the sites' own published favicons.

Other domains use their own `/favicon.ico`. If unavailable, a neutral globe appears; it is a generic website indicator, not an invented brand mark. Images are decorative alongside visible platform names and suppress referrer information.
